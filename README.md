# 🤖 Advanced ML Model Comparison Dashboard

An interactive **Machine Learning Dashboard** built with Streamlit that allows users to compare multiple classification models and analyze how preprocessing techniques impact performance.

---

## 🚀 Live Demo
🔗 https://lnkd.in/gnFAGy9n  

---

## 📌 Project Overview

This application enables users to:
- Upload their own dataset
- Apply preprocessing techniques like feature scaling
- Train and compare multiple ML models
- Visualize performance using evaluation metrics
- Make real-time predictions

---

## ⚙️ Features

✅ Compare multiple ML models:
- Logistic Regression  
- Support Vector Machine (SVM)  
- Random Forest  
- K-Nearest Neighbors (KNN)  

✅ Data preprocessing:
- StandardScaler  
- Normalizer  
- Automatic handling of categorical variables  

✅ Model evaluation:
- Accuracy comparison  
- Confusion Matrix  
- Classification Report  

✅ Interactive capabilities:
- Upload custom dataset  
- Real-time predictions  
- Download model results  

---

## 📊 Dataset Used

**Mall Customers Dataset**

The dataset contains:
- Customer demographics (Age, Gender)
- Annual Income
- Spending Score

A new target column is created:
- `1` → High Spender
